# Three Launcher

Лаунчер для Android 12+ в стиле Pixel Launcher (Kotlin + Jetpack Compose + Material You).

## Возможности

- **Главный экран**: страницы, сетка (4–6 × 4–7), док, папки (перетащите значок на значок), виджеты, «Обзор» (дата и будильник), строка поиска Google внизу.
- **Перетаскивание**: удержание значка → меню быстрых действий (ярлыки приложения, «О приложении», «Убрать», «Удалить»); зоны сверху при перетаскивании; листание страниц у края.
- **Список приложений**: свайп вверх с отслеживанием пальца, поиск, предлагаемые приложения, сортировка, скрытые приложения, размытие обоев.
- **Оформление**: цвета Material You из обоев, формы значков (системная, круг, сквиркл, скруглённый квадрат, капля, квадрат), тематические значки (Android 13+), точки уведомлений, светлая/тёмная тема.
- **Жесты**: свайп вверх — приложения; свайп вниз — шторка уведомлений / поиск; кнопка Home — возврат на первую страницу.
- **Настройки**: удержание на пустом месте → «Настройки главного экрана» (или ⚙ в системных настройках приложений).

## Сборка

```
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`. Нужен JDK 17 и Android SDK (compileSdk 35).
Сборка также запускается в GitHub Actions (`.github/workflows/build.yml`); APK лежит в артефактах запуска, а для тегов `v*` публикуется в Releases.

## Установка

Установите APK → нажмите Home → выберите *Three Launcher* → «Всегда» (или «Назначить» в баннере лаунчера).

> Релизный APK подписан debug-ключом — для личного использования.
